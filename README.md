# To-Do List with LocalStorage

A simple To-Do List web application created using HTML, CSS, and JavaScript.

## Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage

## Features

- Add new tasks
- Delete tasks
- Edit tasks
- Mark tasks as completed
- Save tasks using LocalStorage
- Tasks remain saved after refreshing the page

## How to Use

1. Enter a task.
2. Add the task to the list.
3. Edit, complete, or delete tasks as needed.
4. Your tasks are automatically saved in the browser using LocalStorage.

## Purpose

This project was created for learning JavaScript DOM manipulation, events, and LocalStorage.
